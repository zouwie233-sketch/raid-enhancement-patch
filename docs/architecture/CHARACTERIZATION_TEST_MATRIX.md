# 架构重构特征测试矩阵

状态：设计完成，测试尚未实现  
目的：在拆分结构时证明玩法行为没有意外变化。

## 测试等级

| 等级 | 类型 | 执行位置 | 适用内容 |
|---|---|---|---|
| T1 | 纯 Java 单元/契约测试 | GitHub 构建 | 状态机、门控、队列、配置、迁移、幂等 |
| T2 | NeoForge GameTest | GitHub 构建或专用测试实例 | 世界交互、实体生成、碰撞、事件顺序 |
| T3 | 单人整合测试 | 指定测试版本目录 | 退出主菜单、重新进入、BossBar、最终连续波次 |
| T4 | 多人/专服压力测试 | 专用服务端 | 多玩家、多袭击、多维度、性能和日志容量 |

## 性能守门用例

| ID | 场景 | 通过条件 |
|---|---|---|
| PERF-001 | 无活动袭击的服务器运行 | 不执行袭击者 AABB 扫描或全实体遍历 |
| PERF-002 | 多个同时袭击 | 每级世界共享生成和扫描预算，不按袭击数量无限放大 |
| PERF-003 | 雇佣兵恢复 | 常规路径由实体事件索引恢复，不调用 `getAllEntities()` |
| PERF-004 | 安全位置搜索耗尽 | 当 tick 预算耗尽时延迟任务，不在同 tick 继续搜索 |
| PERF-005 | 详细诊断开启 | 日志按 raidId/事件限流，单文件遵守轮转上限 |
